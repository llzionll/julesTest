# Babylon.js Client

This directory contains the frontend application built with Babylon.js and Vite.

## Setup

1.  Navigate to the `client` directory:
    ```bash
    cd client
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```

## Running the Client

To start the development server:
```bash
npm run dev
```
This will typically open the application in your browser at `http://localhost:5173`.

The client is configured to automatically connect to the Colyseus server at `ws://localhost:2567`.
